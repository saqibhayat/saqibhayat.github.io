02 / Engineering case studies

Problems solved, not just features shipped.

01Content architecture

Scaling a mobile app to 1,000+ games

A monolithic build was not viable. I led a remote content architecture using Addressables, AssetBundles, Play Asset Delivery and AWS S3.

Catalog→Remote bundles→On-demand delivery
Result

Reduced an approximately 600 MB content footprint to an approximately 130 MB base application.

02Performance engineering

Shipping across the Android device curve

Profiling-led optimization targeted constrained RAM, weaker Mali GPUs, expensive rendering paths and long load sequences.

Profile→Tier devices→Adapt quality
Approach

Memory and CPU/GPU profiling, URP tuning, render-scale control, particle budgets and adaptive quality.

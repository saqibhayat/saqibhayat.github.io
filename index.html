02 / Engineering case studies

Problems solved, not just features shipped.

01Content architecture

Scaling a mobile app to 1,000+ games

A monolithic build would have been impractical. The content pipeline was structured around remote delivery and platform-aware asset management.

Large content library→AssetBundles + PAD + S3→~130 MB base app
Result

Reduced a roughly 600 MB content footprint to an approximately 130 MB base application while retaining access to the broader catalog.

02Performance engineering

Making Unity behave on low-end Android

Performance work focused on constrained RAM, weaker Mali GPUs and rendering configurations that disproportionately hurt real-world devices.

Profile→Device tiers→Adaptive quality
Approach

URP tuning, render-scale control, particle reduction, memory profiling and device-aware quality thresholds.

03Gameplay architecture

Reusable systems for content-heavy games

Repeated interaction patterns become production debt when every level reinvents them. Reusable task abstractions keep production consistent.

Interaction primitives→Reusable task layer→Faster production
Systems

Drag/drop, tools, pouring, scratching, animation sequences, timers, handholding and FTUE orchestration.
